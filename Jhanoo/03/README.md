# [PGS - Lv2] 03_행렬 테두리 회전하기

## ⏰**time**

35분

## :pushpin: **Algorithm**

* Simulation
* 2차원 배열
* 방향 배열

## ⏲️**Time Complexity**

$O(R \times C + \sum P)$

`R`은 행의 개수, `C`는 열의 개수이다.

먼저 `rows × columns` 크기의 행렬을 초기화하는 데 $O(R \times C)$이 걸린다.

각 쿼리마다 회전하는 것은 선택된 직사각형의 테두리뿐이며, 테두리 길이만큼 한 번씩 순회한다.

각 쿼리의 테두리 길이를 `P`라고 하면 전체 시간 복잡도는 다음과 같다.

```text
O(R × C + 모든 쿼리의 테두리 길이 합)
```

즉,

```text
O(R × C + ΣP)
```

이다.

## :round_pushpin: **Logic**

1. `rows × columns` 크기의 2차원 배열을 만들고, 문제 조건에 맞게 왼쪽 위부터 순서대로 숫자를 채운다.

   ```java
   int[][] board = new int[rows][columns];

   int num = 0;

   for (int r = 0; r < rows; r++) {
       for (int c = 0; c < columns; c++) {
           board[r][c] = ++num;
       }
   }
   ```

2. 테두리를 시계 방향으로 이동하기 위해 방향 배열을 만든다.

   이동 순서는 다음과 같다.

   ```text
   오른쪽 → 아래 → 왼쪽 → 위
   ```

   ```java
   int[] dx = {0, 1, 0, -1};
   int[] dy = {1, 0, -1, 0};
   ```

3. 문제에서 주어지는 좌표는 1부터 시작하므로 배열 인덱스에 맞게 0-based로 변환한다.

   ```java
   int x1 = query[0] - 1;
   int y1 = query[1] - 1;
   int x2 = query[2] - 1;
   int y2 = query[3] - 1;
   ```

4. 회전 과정에서 기존 값을 잃지 않기 위해 `prev`와 `cur`을 이용한다.

   가장 왼쪽 위 칸에는 바로 아래에 있던 값이 올라와야 하므로 해당 값을 먼저 저장한다.

   ```java
   int prev = board[x1 + 1][y1];
   int cur = board[x1][y1];

   board[x1][y1] = prev;
   prev = cur;
   ```

5. 회전하면서 이동한 값 중 최솟값도 함께 구한다.

   ```java
   int min = prev;
   ```

6. 현재 위치와 방향을 초기화한다.

   첫 번째 이동 방향은 오른쪽이다.

   ```java
   int r = x1;
   int c = y1;
   int d = 0;
   ```

7. 직사각형의 네 모서리에 도착할 때마다 이동 방향을 변경한다.

   ```java
   if (r == x1 && c == y2) d++;
   if (r == x2 && c == y2) d++;
   if (r == x2 && c == y1) d++;
   ```

   방향은 다음 순서로 변경된다.

   ```text
   오른쪽
      ↓
   아래
      ↓
   왼쪽
      ↓
   위
   ```

8. 현재 방향으로 한 칸 이동한다.

   ```java
   r += dx[d];
   c += dy[d];
   ```

9. 이동한 위치의 기존 값을 `cur`에 저장한 뒤, 해당 위치에 이전 칸의 값을 넣는다.

   ```java
   cur = board[r][c];
   board[r][c] = prev;
   prev = cur;
   ```

   이렇게 하면 별도의 복사 배열 없이 값 하나만 임시 저장하면서 테두리를 회전시킬 수 있다.

10. 회전 과정에서 이동한 값 중 최솟값을 계속 갱신한다.

```java
min = Math.min(min, prev);
```

11. 시작 위치의 바로 아래 칸까지 모두 회전시키면 테두리 한 바퀴가 완성된다.

```java
while (r != x1 + 1 || c != y1) {
    ...
}
```

12. 해당 쿼리에서 회전한 숫자 중 최솟값을 정답 배열에 저장한다.

```java
answer[i] = min;
```

13. 모든 쿼리를 처리한 뒤 정답 배열을 반환한다.

```java
return answer;
```

## :black_nib: **Review**

* 행렬 전체를 돌리는 것이 아니라 주어진 직사각형의 테두리만 회전시키는 시뮬레이션 문제였다.
* 회전 방향을 `오른쪽 → 아래 → 왼쪽 → 위`로 정하고 방향 배열을 사용하니 구현이 단순해졌다.
* 현재 칸의 값을 바로 덮어쓰면 기존 값을 잃어버리므로 `prev`와 `cur`을 이용해 값을 하나씩 전달하는 방식으로 처리했다.
* 회전과 동시에 이동한 값들의 최솟값을 계산하면 별도로 테두리를 다시 순회할 필요가 없었다.
* 각 쿼리에서는 직사각형 내부 전체가 아니라 테두리 길이만큼만 순회하므로 시간 복잡도는 모든 쿼리의 테두리 길이 합에 비례한다.
* 모서리 좌표에서 방향을 정확히 바꾸는 것이 구현의 핵심이었다.
