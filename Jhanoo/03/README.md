# [PGS - Lv2] 03_서버 증설 횟수

## ⏰**time**

16분

## :pushpin: **Algorithm**

* Greedy
* 차분 배열
* 누적합
* 시뮬레이션

## ⏲️**Time Complexity**

$O(N)$

`N`은 시간대의 개수이다.

각 시간대를 한 번씩 순회하면서 현재 운영 중인 서버 수를 계산하고, 필요한 경우 증설 서버 수를 구한다.

따라서 전체 시간 복잡도는 $O(N)$이다.

문제에서는 시간대가 24개로 고정되어 있으므로 실제로는 상수 시간에 가깝다.

## :round_pushpin: **Logic**

1. 각 시간대에서 필요한 서버 수는 해당 시간대의 이용자 수를 서버 1대가 감당할 수 있는 인원 `m`으로 나눈 값이다.

   ```java
   int needServerCnt = players[i] / m;
   ```

   예를 들어 서버 1대가 `m = 3`명을 처리할 수 있을 때:

   ```text
   이용자 0~2명  → 추가 서버 0대
   이용자 3~5명  → 추가 서버 1대
   이용자 6~8명  → 추가 서버 2대
   ```

2. 서버는 증설한 시점부터 `k`시간 동안 운영된다.

   각 시간대별 서버 수를 직접 모두 갱신하는 대신, 차분 배열을 사용해 서버의 시작과 종료만 기록한다.

   ```java
   int[] servers = new int[24 + k];
   ```

3. 이전 시간대까지의 서버 변화량을 누적해 현재 운영 중인 서버 수를 계산한다.

   ```java
   if (i > 0) {
       servers[i] += servers[i - 1];
   }
   ```

   `servers[i]`에는 현재 시간대에 실제로 운영 중인 증설 서버 수가 저장된다.

4. 현재 시간대에 필요한 서버 수와 운영 중인 서버 수를 비교한다.

   ```java
   int needServerCnt = players[i] / m;

   if (needServerCnt > servers[i]) {
   }
   ```

5. 운영 중인 서버가 부족하다면 부족한 수만큼만 새로 증설한다.

   ```java
   int newServerCnt = needServerCnt - servers[i];
   ```

   현재 시간대의 요구량을 만족하기 위해 필요한 최소한의 서버만 추가하므로 그리디하게 최적의 선택이 된다.

6. 새로 증설한 서버는 현재 시간대부터 바로 운영되므로 현재 서버 수에 더한다.

   ```java
   servers[i] += newServerCnt;
   ```

7. 증설한 서버는 `k`시간 후 운영이 종료된다.

   따라서 `i + k` 위치에 서버 수 감소량을 기록한다.

   ```java
   servers[i + k] -= newServerCnt;
   ```

   이후 누적합을 계산하면 `i + k` 시점부터 해당 서버가 자동으로 제외된다.

8. 증설한 서버 수를 전체 증설 횟수에 더한다.

   ```java
   answer += newServerCnt;
   ```

9. 24시간을 모두 확인한 뒤 총 서버 증설 횟수를 반환한다.

   ```java
   return answer;
   ```

## :black_nib: **Review**

* 처음에는 서버를 증설할 때마다 이후 `k`개의 시간대를 직접 갱신할 수도 있지만, 차분 배열을 사용하면 시작 시점과 종료 시점만 기록할 수 있었다.
* 이전 시간대의 값을 누적해 현재 운영 중인 서버 수를 계산하는 방식이 호텔 대실 문제의 시간 누적 방식과 비슷했다.
* 각 시간대에서 부족한 서버 수만큼만 증설하면 이후 시간대에도 해당 서버가 유지되므로 최소 증설 횟수를 구할 수 있었다.
* 증설한 서버가 `k`시간 동안 유지되므로 `servers[i + k]`에서 감소시키는 것이 핵심이었다.
* `servers` 배열의 크기를 `24 + k`로 만들어 마지막 시간대에서 서버 종료 시점을 기록해도 인덱스 범위를 벗어나지 않도록 했다.
* 각 시간대를 한 번씩만 확인하므로 전체 시간 복잡도는 $O(N)$이다.
