# [PGS - Lv2] 02_두 원 사이의 정수 쌍

## ⏰**time**

32분

## :pushpin: **Algorithm**

- 수학
- 기하
- 완전탐색
- 대칭성

## ⏲️**Time Complexity**

$O(R_2)$

`x` 좌표를 `1`부터 `r2`까지 한 번씩 확인한다.

각 `x`에 대해 두 원에서 가능한 최소 `y`, 최대 `y`를 `sqrt()`를 이용해 상수 시간에 계산하므로 전체 시간 복잡도는

```text
O(r2)
```

이다.

## :round_pushpin: **Logic**

1. 반지름이 `r`인 원 위의 좌표는 다음 관계를 만족한다.

   ```text
   x² + y² = r²
   ```

   따라서 특정 `x`가 정해졌을 때 원 위의 `y`는

   ```text
   y = sqrt(r² - x²)
   ```

   로 구할 수 있다.

2. 두 원 사이에 있는 점은 다음 조건을 만족해야 한다.

   ```text
   r1² <= x² + y² <= r2²
   ```

3. 하나의 `x`를 고정했을 때 바깥쪽 원 안에 존재할 수 있는 가장 큰 정수 `y`를 구한다.

   ```java
   long y2 = (long) Math.floor(
       Math.sqrt((long) r2 * r2 - x * x)
   );
   ```

   바깥쪽 원의 내부 또는 원 위에 있어야 하므로 `floor()`를 사용한다.

4. 안쪽 원의 바깥 또는 원 위에 있어야 하므로 가능한 가장 작은 정수 `y`를 구한다.

   ```java
   long y1 = (long) Math.ceil(
       Math.sqrt((long) r1 * r1 - x * x)
   );
   ```

   안쪽 원보다 바깥에 있어야 하므로 `ceil()`을 사용한다.

   다만 `x >= r1`이면 이미

   ```text
   x² >= r1²
   ```

   이므로 `y = 0`부터 조건을 만족한다.

   의도를 명확하게 표현하려면 다음처럼 처리할 수 있다.

   ```java
   long y1 = 0;
   
   if (x < r1) {
       y1 = (long) Math.ceil(
           Math.sqrt((long) r1 * r1 - x * x)
       );
   }
   ```

5. 현재 `x`에서 가능한 정수 `y`는 `y1`부터 `y2`까지이므로 개수는 다음과 같다.

   ```java
   y2 - y1 + 1
   ```

6. 원은 원점을 기준으로 대칭이므로 한쪽 영역에서 구한 점의 개수를 이용해 전체 좌표를 계산한다.

   ```java
   answer += (y2 - y1 + 1) * 4;
   ```

7. `x = 0`을 직접 세지 않고 `x = 1`부터 시작한다.

   ```java
   for (long x = 1; x <= r2; x++) {
       ...
   }
   ```

   이 방식에서는 `y = 0`인 x축 위의 점을 4배하면서 실제보다 2개씩 더 세지만, 반대로 세지 않은 y축 위의 점이 동일한 개수만큼 존재하므로 서로 상쇄된다.

8. 제곱 연산에서는 `int` 범위를 초과할 수 있으므로 곱하기 전에 `long`으로 변환한다.

   ```java
   (long) r1 * r1
   (long) r2 * r2
   ```

   다음처럼 작성하면 `int` 연산이 먼저 수행될 수 있으므로 주의해야 한다.

   ```java
   r2 * r2
   ```

9. 모든 `x`에 대해 가능한 정수 좌표를 계산한 뒤 결과를 반환한다.

   ```java
   return answer;
   ```

## :black_nib: **Review**

- 처음에는 두 원 사이의 모든 `(x, y)` 좌표를 직접 확인하는 방법을 생각할 수 있지만, 좌표 범위가 크기 때문에 `x` 하나를 고정하고 가능한 `y`의 범위를 계산하는 방식으로 접근했다.
- 원의 방정식 `x² + y² = r²`을 이용하면 특정 `x`에서 가능한 `y`의 범위를 바로 계산할 수 있었다.
- 바깥쪽 원은 내부에 포함되어야 하므로 `floor`, 안쪽 원은 바깥쪽에 있어야 하므로 `ceil`을 사용해야 했다.
- 원의 대칭성을 이용해 한쪽 영역만 계산한 뒤 4배하여 전체 좌표 개수를 구할 수 있었다.
- `x = 0`을 제외하고 계산하면 축 위 점의 중복 처리를 별도로 하지 않고도 4배하는 방식으로 처리할 수 있었다.
- 반지름을 제곱할 때 `int` 오버플로우가 발생할 수 있으므로 곱셈 전에 `long`으로 변환해야 했다.
- `x >= r1`에서는 안쪽 원의 최소 `y`가 `0`이 된다는 점을 명시적으로 처리하면 코드의 의도가 더 명확해진다.
