# [PGS - Lv1] 01_직사각형 별찍기

## ⏰**time**
5분

## :pushpin: **Algorithm**
반복문

## ⏲️**Time Complexity**
$O(a*b)$

## :round_pushpin: **Logic**
1. 이중 for문을 이용해서 *을 출력한다.
   ```cpp
   for(int i =0;i<b;i++){
       for(int j=0;j<a;j++){
           cout << "*";
       }
       cout << '\n';
   }
   ```
