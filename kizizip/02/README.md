## :round_pushpin: **Logic**

1. p를 숫자로 변환하고, 비교할 부분 문자열의 개수를 계산
2. t에서 길이가 p와 같은 부분 문자열을 하나씩 추출
3. 각 부분 문자열을 숫자로 변환해 p보다 작거나 같으면 answer 증가
4. 모든 부분 문자열을 확인한 후 answer를 반환
