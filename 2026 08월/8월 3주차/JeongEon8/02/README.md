# [PGS - Lv1] 02_x만큼 간격이 있는 n개의 숫자

2분

## :pushpin: **Algorithm**

## ⏲️**Time Complexity**

## :round_pushpin: **Logic**
1. x를 계속 n번 만큼 곱해준다.
   ```cpp
    for(int i = 1; i <= n; i++){
        answer.push_back(x*i);
    }
   ```
