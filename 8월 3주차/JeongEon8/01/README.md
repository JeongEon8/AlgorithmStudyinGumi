## :pushpin: **Algorithm**

## :round_pushpin: **Logic**
1. 배열 속 숫자를 모두 더해, 배열의 크기만큼으로 나눈다.
   ```cpp
    for(int i = 0; i < arr.size(); i++){
        answer += arr[i];
    }
    
    answer /= arr.size();
   ```
